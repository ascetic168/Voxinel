# 03 按住說話（PTT）

預設的語音輸入方式：按住熱鍵說話，放開後辨識完成自動貼上。這是最接近「用說的打字」的模式。

## 基本流程

1. 按住 `Ctrl`（或您設定的組合鍵）開始說話
2. 說話同時，畫面下方的 Overlay 浮動視窗**邊說邊出字**（串流辨識）
3. 放開熱鍵，離線引擎（SenseVoice）對整段音訊做高精度辨識與標點修正
4. 修正後的文字自動**貼上**到您按熱鍵時的目標視窗
5. 原本剪貼簿的內容自動還原

## Overlay 顯示說明

Overlay 浮動視窗出現在主螢幕下方中間，不會搶走焦點（點擊與輸入仍作用在您的工作視窗）：

| 顏色 | 意義 |
|---|---|
| 淺藍色文字 | 已確定的辨識結果 |
| 琥珀色（淡黃）文字 | 串流即時預測，尚待修正 |

放開熱鍵後，琥珀色的部分會被 SenseVoice 的高精度結果（含標點）替換，然後貼上並關閉 Overlay。

## 雙引擎如何協作

- **串流引擎（Zipformer）**：按下熱鍵的瞬間就開始辨識，負責即時反饋，讓您邊說邊確認
- **離線引擎（SenseVoice）**：放開後對完整音訊重新辨識，負責最終品質，支援中、英、日、韓、粵，自動加標點

## 什麼情況會取消或不出文字

- 按住不到 0.5 秒、或錄音短於 0.8 秒 → 自動取消／丟棄
- 錄音中按了任何其他鍵 → 立即取消（放開前想喊卡，按任意鍵即可）
- 辨識結果為空 → 不貼上
- 全部細節見[快捷鍵與防誤觸](02-hotkeys.md)

## 使用雲端引擎時的差異

把[騰訊雲或 Gemini 排在第一位](08-engines.md)時，一樣按住說話、放開貼上，但**沒有邊說邊出字**：放開後整段音訊（先經 VAD 去除靜音）送往雲端辨識，完成後貼上。想保留即時顯示，請把本地引擎排在第一位。

## 小技巧

- 說太短（<0.8 秒）沒有結果是正常的防誤觸行為，不是壞掉
- 若放開後離線修正遲遲未回來（超過 5 秒），程式會直接貼上串流結果，不會讓您卡住
- 辨識期間切換視窗也不用擔心——貼上目標在按熱鍵當下已鎖定，程式會自動帶回焦點
