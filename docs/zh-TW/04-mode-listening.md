# 04 傾聽模式

連續聽寫：開啟後 Voxinel 持續聆聽麥克風，**每說完一句就自動辨識並貼上一句**，直到您關閉為止。適合長段落口述、邊想邊說的場景。

## 開啟／關閉

- **連按兩下右 `Ctrl` 鍵**（1 秒內按兩下）— 再操作一次即關閉
- 或從系統托盤選單點「傾聽模式」切換

## 使用要點

- **貼上目標在開啟模式那一刻鎖定**為當時的前景視窗，之後每一句都貼到那裡。想換視窗：先關閉模式，到目標視窗再開啟
- 每一句都經過 SenseVoice 離線修正並自動加標點
- Overlay 顯示「🎙️ Mic 傾聽」標籤並有**綠色呼吸燈外框**，方便確認目前狀態
- 關閉時，已錄到但尚未辨識完的句子會先貼完才結束（排空行為），不會漏字
- **此模式不產生記錄檔**——輸出只有貼上的文字；需要留檔請改用[即時字幕](05-mode-caption.md)或[會議模式](06-mode-conference.md)

## 典型使用流程

1. 把游標放到要輸入文字的地方（例如編輯器）
2. 連按兩下右 Ctrl 開啟傾聽模式
3. 開口說話——每說完一句，該句自動出現在游標位置
4. 講完後再連按兩下右 Ctrl 關閉

## 與其他模式的關係

- 開啟傾聽模式時，其他模式（字幕／會議）會自動停止（模式互斥）
- 傾聽模式啟用中，按住說話（PTT）暫時停用，避免同時錄音
