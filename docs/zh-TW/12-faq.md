# 12 常見問題與疑難排解

## 語音輸入

### 按住 Ctrl 說話，放開後沒有文字出現？

依序檢查：

1. **說話時間是否太短**——少於 0.8 秒的錄音會自動丟棄（防誤觸設計）
2. **是否設定了辨識來源**——設定頁「語音辨識來源」至少要有一個；全部來源失敗時也不會有文字
3. **模型是否下載完成**——重新開啟設定視窗，缺模型時會自動跳出下載視窗
4. **是否在錄音中按了其他鍵**——錄音中按任何其他鍵都會立即取消

### 文字被貼到錯誤的視窗？

貼上目標在「按下熱鍵那一刻」鎖定，辨識完成後程式會自動把焦點帶回該視窗再貼上。少數特殊應用（全螢幕遊戲、以系統管理員權限執行的視窗）可能不接受模擬貼上。

### Ctrl 跟輸入法切換／其他快捷鍵打架？

錄音中按任何其他鍵會立即取消錄音，Ctrl 會完整讓給原快捷鍵；按住 Shift／Alt 等修飾鍵時按 Ctrl 也不會觸發錄音。若仍有困擾，可在設定頁把熱鍵改為 `Ctrl + Win` 等組合鍵。

### 鍵盤偶爾殘留怪字元？

v0.5.10 已修正（空辨識結果不再送出模擬貼上按鍵）。請更新到最新版。

## 各模式

### 傾聽模式的文字貼到別的視窗？

傾聽模式的貼上目標在**開啟模式那一刻**鎖定。換視窗：先連按兩下右 Ctrl 關閉，到目標視窗再開啟。

### 即時字幕／會議模式開啟後沒有字幕？（Windows）

1. 確認正在發聲的裝置是 Windows **預設**播放裝置——擷取的是預設裝置的混音
2. 藍牙耳機等非預設裝置播放時收不到，先到音效設定切換預設裝置
3. macOS / Linux 不支援系統音訊擷取

### 會議模式大家都顯示 unknown？

- 少於 0.5 秒的片段一律標 unknown，請以正常速度說話
- 聲紋需要累積，同一人說越多句越準
- 到「聲紋辨識管理」把 `Speaker_N` 改名為真實姓名，之後的記錄就會顯示名字

### AI 助手叫不醒？

1. 確認設定頁「AI 助手模式」已啟用（預設開）
2. 其他模式（傾聽／字幕／會議）進行中時不會背景監聽
3. 喚醒詞要完整說出並被正確辨識；最可靠的是直接按 `Ctrl+Shift+L`
4. 助手視窗開啟時 PTT 會停用，這是防誤觸設計

### 設定視窗不小心關掉了？

按 X 只是縮回托盤。點系統托盤圖示 →「設置」即可再開啟。

## AI 功能

### AI 校稿／摘要沒有作用？

1. 確認設定頁已勾選對應功能
2. 確認 LLM 端點可用（見[AI 功能與 LLM 設定](10-ai-features.md)）：本機 Ollama 是否運行、模型名稱是否正確
3. 端點在程式啟動時做健康檢查——若啟動當下 Ollama 還沒開，開好後重啟 Voxinel

### AI 助手一直停在「思考中」？

檢查 Base URL、模型名稱、API Key。使用 Ollama 時，用 `ollama list` 確認設定的模型存在。

## 引擎與模型

### 模型下載失敗或太慢？

- 简体中文系統會自動使用鏡像站加速；若您在中國大陸網路環境但系統不是简体中文，可暫時把設定頁的界面語言設為「简体中文」再下載
- 確認磁碟剩餘空間至少 600MB
- 下載中斷的話，重新開啟設定視窗即可再次觸發下載

### 可以只用雲端引擎嗎？

可以。把雲端來源排第一位即可，按住說話流程不變，只是沒有邊說邊出字的即時顯示（見[引擎說明](08-engines.md)）。

## 平台與其他

### macOS / Linux 支援度？

可安裝、可使用基本語音輸入、支援開機自啟；但「即時字幕」「會議模式」（系統音訊擷取）與「自動貼上」目前僅在 Windows 實作。

### 如何診斷問題？

以 `--debug` 參數啟動，會開啟主控台視窗顯示詳細訊息。Voxinel 平時不寫日誌檔。
