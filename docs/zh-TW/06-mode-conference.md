# 06 會議模式與聲紋辨識 🧪

同時擷取**麥克風（近端：您說的話）**與**系統音訊（遠端：對方或會議播放的聲音）**，雙字幕即時顯示；關閉時自動合併成帶時間戳與說話人標示的逐字稿，並可自動產生 AI 會議摘要。

> ⚠️ 遠端音訊擷取（loopback）目前**僅支援 Windows**。🧪 表示實驗性功能。

## 開啟／關閉

1. 系統托盤選單 →「會議模式」（需已下載串流模型）
2. 畫面**上方**出現紫色「🔊 遠端」字幕視窗、**下方**出現綠色「🎤 近端」字幕視窗
3. 結束時點托盤選單（顯示「關閉會議模式」），自動存檔

## 回音抑制

遠端的聲音從喇叭播出來時也會進到您的麥克風，造成「同一句話被錄兩次」。會議模式內建回音抑制：偵測到遠端說話時暫時忽略麥克風音訊，遠端停止說話約 0.5 秒後恢復收音。**搭配耳機使用效果最佳**。

## 說話人聲紋標示

- 內建聲紋辨識：每位首次出現的說話人會自動註冊為 `Speaker_1`、`Speaker_2`……不需手動建檔
- 之後聽到同一人，字幕與逐字稿會標示 `[Speaker_1]`；累積發言越多，辨識越穩定
- 少於 0.5 秒的短片段一律標為 unknown（不明說話人）

### 聲紋辨識管理

系統托盤選單 →「聲紋辨識管理」開啟管理視窗：

| 操作 | 作用 |
|---|---|
| 重新命名 | 把 `Speaker_1` 改成真實姓名，之後的記錄檔與字幕就會顯示該名字 |
| 刪除 | 移除某位說話人的聲紋資料 |
| 合併 | 重新命名成既有名字時，會詢問是否把兩筆聲紋合併為同一人 |

聲紋資料儲存於模型目錄下的 `speaker\speakers.db`（SQLite），**只存在本機**。

## 逐字稿與 AI 摘要

關閉模式時依序執行：

1. 近端與遠端文字依時間排序合併，存為 `Documents\Voxinel\conference_YYYYMMDD_HHMMSS.txt`。同一發言人連續發言合併為一個區塊，只在區塊首行標時間與發言人：

```
# 會議記錄 — 2026-10-31 14:00:00
# 時長: 1830.0 秒 | 遠端: 42 段 | 近端: 18 段

[14:00:12] 遠端 [Speaker_1]：
大家早安，我們開始今天的會議
今天主要討論三件事

[14:00:25] 近端：
好的，我先報告上週進度
```

2. 若啟用「AI 輔助校稿」→ 先以 LLM 修正錯字與標點再存檔
3. 若啟用「AI 會議摘要」→ 額外產生 `conference_summary_YYYYMMDD_HHMMSS.md`，內容包含摘要、與會者、討論主題、重要決議、行動項目等段落（見[AI 功能與 LLM 設定](09-ai-features.md)）

## 僅記錄、不顯示字幕

設定頁 →「系統設置」→ 勾選「會議模式：隱藏即時字幕視窗（僅記錄）」：會議中不會出現任何 Overlay 視窗，只在背景辨識與存檔，適合不想讓畫面出現字幕的正式場合。

## 使用建議

- 會議中戴耳機，回音抑制效果最佳
- Google Meet、Teams 等會議軟體的聲音會經系統音訊擷取，不需另外設定
- 遠端聽不到時，檢查會議播放裝置是否為 Windows 預設播放裝置
