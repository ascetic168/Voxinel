# 02 快捷鍵與防誤觸

## 快捷鍵速查

| 功能 | 操作 | 可否自訂 |
|---|---|---|
| 按住說話（PTT） | 按住 `Ctrl` 說話，放開辨識並貼上 | ✅ 可從五種組合中選擇 |
| 開啟／關閉傾聽模式 | 1 秒內連按兩下**右** `Ctrl` | ❌ 固定 |

## 按住說話的熱鍵組合

設定頁「識別設置」→「快捷鍵」可從以下五種組合中選擇，修改後立即生效：

| 選項 | 適合 |
|---|---|
| `Ctrl`（單鍵，預設） | 最順手；內建完整防誤觸判斷（見下節） |
| `Ctrl + Win` | 想徹底避免與日常 Ctrl 快捷鍵互動的使用者 |
| `Ctrl + Shift` | — |
| `Ctrl + Alt` | — |
| `Shift + Alt` | — |

## 單鍵 Ctrl 的防誤觸規則

單鍵 Ctrl 意味著它和日常的 Ctrl+C / Ctrl+V 共用同一顆鍵，因此程式內建一整套使用意圖判斷，正常操作完全不受影響：

| 規則 | 行為 |
|---|---|
| 其他修飾鍵按著時不啟動 | 按住 Shift／Alt／Win 的情況下按 Ctrl，不會開始錄音（輸入法切換等組合鍵不會誤觸） |
| 按住不到 0.5 秒 | 自動取消，快速點一下 Ctrl 不會錄音 |
| 錄音中按任何其他鍵 | **立即取消**——例如按下 Ctrl 後臨時改按 Ctrl+C，錄音馬上取消，複製照常進行 |
| 錄音短於 0.8 秒 | 自動丟棄，不產出垃圾文字 |
| 辨識結果為空 | 完全不送出貼上按鍵，鍵盤不會殘留怪字元 |
| 自動貼上後 0.2 秒內 | 貼上用的模擬 Ctrl 不會被誤判成新的錄音指令 |

## 貼上與剪貼簿

- 辨識完成後，程式以模擬 `Ctrl+V` 貼上文字，並**自動還原您原本的剪貼簿內容**（純文字部分）
- 貼上目標在**按下熱鍵那一刻**就鎖定為當時的前景視窗；辨識完成後程式會把焦點帶回該視窗再貼上，避免貼錯地方
- Voxinel 自己的視窗、工作列、開始選單等系統介面不會成為貼上目標

## 全域性規則

- PTT 在**傾聽模式啟用中**時會暫時停用，避免兩邊同時錄音
- 熱鍵修改後立即生效，不需重啟程式
