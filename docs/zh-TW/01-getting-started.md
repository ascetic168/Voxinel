# 01 開始使用

## 系統需求

| 項目 | 需求 |
|---|---|
| 作業系統 | Windows 10 / 11（完整功能）；macOS、Linux 可安裝但有限制（見下方注意） |
| 麥克風 | 使用語音輸入、傾聽、會議、AI 助手模式時需要 |
| 磁碟空間 | 首次下載模型約需 **600MB** |
| 網路 | 僅首次下載模型需要，之後**完全離線** |
| GPU | **不需要**。純 CPU 即可流暢運行 |

> **macOS / Linux 注意**：設定、語音輸入基本功能、開機自啟皆可用；但「即時字幕」與「會議模式」依賴的系統音訊擷取（loopback），以及辨識結果的自動貼上，目前僅在 Windows 上實作。詳見[常見問題](12-faq.md)。

## 安裝

1. 前往 [GitHub Releases](https://github.com/ascetic168/Voxinel/releases) 頁面下載最新版安裝檔
2. 執行安裝程式，完成後 Voxinel 會常駐在系統托盤（工具列右下角的 🎤 圖示）
3. Voxinel 是單一執行個體程式：重複啟動不會開出第二份，只會聚焦到原有程序

## 首次啟動與模型下載

1. 第一次啟動時，設定視窗會自動開啟，並跳出「正在下載語音辨識模型...」視窗，自動開始下載
2. 下載順序：離線辨識模型（SenseVoice）→ 串流辨識模型（Zipformer）→ VAD → 聲紋辨識 → TTS 語音合成
3. 進度條會顯示目前項目與「已下載 / 總大小」；全部完成後顯示「模型下載完成」並自動關閉
4. 下載完成即可使用，**無需申請任何 API 金鑰**

模型合計約 600MB，存放於系統模型目錄（位置見[檔案與資料位置](11-data-and-files.md)）。若下載失敗，重新開啟設定視窗即可再次觸發下載。

> **中國大陸網路加速**：系統語言為简体中文時，模型下載會自動改用鏡像站（hf-mirror.com），不需手動設定。

## 系統托盤

Voxinel 平時常駐系統托盤，**左鍵點一下圖示**即可開啟選單：

| 選單項目 | 作用 |
|---|---|
| 傾聽模式 | 開啟／關閉[傾聽模式](04-mode-listening.md)（啟用時顯示「關閉傾聽模式」） |
| 即時字幕模式 | 開啟／關閉[即時字幕模式](05-mode-caption.md) |
| 會議模式 | 開啟／關閉[會議模式](06-mode-conference.md) |
| AI 助手模式 | 開啟／關閉[AI 助手模式](07-mode-assistant.md) |
| 聲紋辨識管理 | 開啟[說話人聲紋管理視窗](06-mode-conference.md#聲紋辨識管理) |
| 設置 | 開啟[設定視窗](09-settings.md) |
| 打開記錄檔目錄 | 用檔案總管開啟記錄檔資料夾（`Documents\Voxinel`） |
| 結束 | 完全結束 Voxinel |

設定視窗按 X 關閉只是縮回托盤，程式仍繼續運行；要完全結束請用托盤選單的「結束」。

## 開機自動啟動

設定視窗 →「系統設置」→ 勾選「系統開機時載入執行」，三個平台（Windows / macOS / Linux）皆支援。

## 更新程式

Voxinel **不會自動更新**。新版發布時，到 [Releases](https://github.com/ascetic168/Voxinel/releases) 下載新安裝檔直接安裝即可，原有的設定與模型都會保留。
