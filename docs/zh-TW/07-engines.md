# 07 語音辨識來源（ASR 引擎）

Voxinel 支援三種語音辨識來源，可同時設定多個並排定**優先順序**：辨識時從第一位開始嘗試，失敗自動換下一個（Fallback）。

## 本地雙引擎（預設，免金鑰）

| 引擎 | 角色 | 說明 |
|---|---|---|
| 串流 Zipformer | 即時辨識 | 中英雙語串流模型，邊說邊出字；用於按住說話的即時顯示，以及傾聽／字幕／會議模式 |
| SenseVoice-Small（INT8） | 離線修正 | 高精度離線辨識，支援中、英、日、韓、粵，自動加標點 |

- 全程在本機 CPU 運算，音訊不出電腦
- 模型首次啟動自動下載（合計約 600MB）；简体中文系統自動改用鏡像站加速
- 模型位置見[檔案與資料位置](10-data-and-files.md)

## 騰訊雲 ASR

- 服務：SentenceRecognition（單句同步辨識）
- 需在騰訊雲控制台取得 **Secret ID** 與 **Secret Key**
- 可選引擎模型：

| 模型 | 語言 |
|---|---|
| `16k_zh` | 普通話 |
| `16k_zh_video` | 普通話（視頻場景） |
| `16k_en` | 英文 |
| `16k_yue` | 粵語 |
| `16k_ca` | 川渝方言 |

## Google Gemini

- 雲端 AI 語音辨識，需 **API Key**（自 Google AI Studio 取得）
- 可選模型：`gemini-3.5-transcribe`（預設）、`gemini-3.5-flash`、`gemini-3.5-flash-lite`、`gemini-3.8-flash`
- 自動加標點、自動移除語氣詞；輸出語言跟隨界面語言設定（繁中／简中／日／韓／英，其他情況依音訊實際語言）
- 注意：Gemini 的結果**不做繁簡轉換**——它會直接照設定的輸出語言給文字

## 優先順序與自動 Fallback

設定頁「語音辨識來源」區塊：

- **新增來源**：填入任一來源的憑證即自動啟用並加入清單
- **▲／▼**：調整優先順序（數字小的先辨識）
- **✕**：移除來源
- **測試連線**：檢查目前選定來源的設定

辨識流程：從第一位開始嘗試 → 該來源失敗（未填金鑰、網路錯誤、額度問題）→ 自動換下一個 → 全部失敗則這次不出文字。

> **即時顯示只跟第一位有關**：串流邊說邊出字只在「本地引擎排第一」時啟用。排第一的是雲端引擎時，流程變成放開熱鍵後整段送往雲端、完成後貼上，畫面沒有即時預覽。

## 環境變數（進階）

憑證也可以用環境變數提供（設定頁未填時的後備）：

| 變數 | 用途 |
|---|---|
| `TENCENTCLOUD_SECRET_ID` / `TENCENTCLOUD_SECRET_KEY` | 騰訊雲憑證 |
| `GEMINI_API_KEY` | Gemini 金鑰 |
