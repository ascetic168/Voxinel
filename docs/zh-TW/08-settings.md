# 08 設定頁完整參考

開啟方式：系統托盤選單 →「設置」。修改後按「**保存設置**」才會生效；「取消」還原未保存的變更。設定視窗按 X 只是縮回托盤。

## 語音辨識來源

| 欄位 | 說明 | 預設 |
|---|---|---|
| 來源清單 | 已啟用的辨識來源，編號即優先順序；點項目展開詳細設定 | 本地 Offline (SenseVoice) |
| ▲ / ▼ / ✕ | 調整順序／移除來源 | — |
| Provider / 模型 | 選擇來源與模型（各來源可選模型見[引擎說明](07-engines.md)） | — |
| 憑證欄位 | 依來源不同：Secret ID／Secret Key（騰訊雲）、API Key（Gemini）、模型目錄（本地，一般不需修改） | 空 |
| 測試連線 | 檢查目前選定來源的設定 | — |

> 未設定任何來源時，頁面會顯示警示「請至少設定一個語音辨識來源」。

## 識別設置

| 欄位 | 說明 | 預設 |
|---|---|---|
| 快捷鍵 | 按住說話的熱鍵組合（五選一，見[快捷鍵](02-hotkeys.md)） | `Ctrl`（單鍵） |
| 簡繁轉換 | 自動（依系統地區）／正體中文／不轉換；串流與最終結果皆適用 | 自動 |

## 語言

| 欄位 | 說明 | 預設 |
|---|---|---|
| 界面語言 | 自動（偵測系統語言）／繁體中文／简体中文／English | 自動 |

## 語音活動偵測（VAD）

| 欄位 | 說明 | 預設 |
|---|---|---|
| 過濾靜音片段 | 自動略過靜音與停頓，避免背景噪音被辨識成怪字 | ✅ 開 |
| 敏感度 | 0.1–0.9。**數值越低越敏感**（越多聲音通過），越高過濾越嚴格 | 0.50 |

## 系統設置

| 欄位 | 說明 | 預設 |
|---|---|---|
| 系統開機時載入執行 | 開機自動啟動 Voxinel | ❌ 關 |
| 會議模式：隱藏即時字幕視窗（僅記錄） | 會議模式不顯示 Overlay，僅背景辨識與存檔 | ✅ 開 |

## AI 輔助校稿

| 欄位 | 說明 | 預設 |
|---|---|---|
| 啟用 AI 校稿 | 關閉字幕／會議模式時，先以 LLM 修正文稿（錯字、標點、合併斷句）再存檔 | ❌ 關 |
| Base URL | OpenAI 相容 API 位址；Ollama 或 OpenAI 填根目錄即可，其他服務需含完整路徑 | `http://localhost:11434` |
| 模型名稱 | LLM 模型 id | `gemma4:latest` |
| API Key | 留空表示不需認證（如本機 Ollama） | 空 |

## AI 會議摘要

| 欄位 | 說明 | 預設 |
|---|---|---|
| 啟用 AI 會議摘要 | 會議結束存檔時自動產生結構化摘要；使用與 AI 校稿**相同的 LLM 設定** | ❌ 關 |## 關於
