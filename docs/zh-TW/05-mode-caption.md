# 05 即時字幕模式 🧪

把**電腦正在播放的聲音**即時轉成字幕：影片、線上課程、演講、通話另一端的聲音，都會在畫面下方即時顯示字幕；關閉時自動存成文字記錄檔。

> ⚠️ 需擷取系統音訊迴路（loopback），目前**僅支援 Windows**。🧪 表示實驗性功能。

## 開啟／關閉

1. 系統托盤選單 →「即時字幕模式」
2. 畫面下方出現**紫色外框**的字幕視窗，開始顯示字幕
3. 再點一次選單（此時顯示「關閉即時字幕」）即結束並自動存檔

## 字幕視窗

- 預設顯示 **5 行**字幕（可在設定頁調整 3–15 行），自動捲動到最新一句
- 同一行內：**藍色**為已確定文字，**琥珀色**為即時預測
- 實驗特性「中途修正」：句子還在進行時，SenseVoice 會提前對前段音訊做離線辨識，把已修正的內容提前以藍色呈現，後面尚未修正的續接琥珀色，讓長句不必等到整句說完才看到高品質文字

## 記錄檔

關閉模式時自動儲存到 `Documents\Voxinel\caption_YYYYMMDD_HHMMSS.txt`：

```
# 即時字幕記錄 — 2026-10-31 14:05:00
# 時長: 123.4 秒
[14:05:02] 這裡是第一句字幕
[14:05:09] 這裡是第二句字幕
```

若啟用「AI 輔助校稿」，存檔前會先以 LLM 修正錯字與標點（見[AI 功能與 LLM 設定](09-ai-features.md)）。托盤選單「打開記錄檔目錄」可快速開啟存放資料夾。

## 常見問題

- **字幕完全沒動？** 本模式擷取的是 Windows **預設播放裝置**的混音。若聲音從非預設裝置（如藍牙耳機）播出，請先到 Windows 音效設定把該裝置設為預設
- 遠端桌面等聽不到系統聲音的環境無法使用
- 會議請改用功能更完整的[會議模式](06-mode-conference.md)（含麥克風與說話人標示）
