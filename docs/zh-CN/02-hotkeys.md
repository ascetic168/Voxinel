# 02 快捷键与防误触

## 快捷键速查

| 功能 | 操作 | 可否自定义 |
|---|---|---|
| 按住说话（PTT） | 按住 `Ctrl` 说话，放开识别并贴上 | ✅ 可从五种组合中选择 |
| 开启／关闭倾听模式 | 1 秒内连按两下**右** `Ctrl` | ❌ 固定 |
| 直接呼叫 AI 助手 | `Ctrl+Shift+L` | ❌ 固定 |
| 唤醒 AI 助手 | 说出唤醒词（默认「小花同学」） | ✅ 唤醒词可自定义 |

## 按住说话的热键组合

设置页「识别设置」→「快捷键」可从以下五种组合中选择，修改后立即生效：

| 选项 | 适合 |
|---|---|
| `Ctrl`（单键，默认） | 最顺手；内建完整防误触判断（见下节） |
| `Ctrl + Win` | 想彻底避免与日常 Ctrl 快捷键互动的用户 |
| `Ctrl + Shift` | — |
| `Ctrl + Alt` | — |
| `Shift + Alt` | — |

## 单键 Ctrl 的防误触规则

单键 Ctrl 意味着它和日常的 Ctrl+C / Ctrl+V 共用同一颗键，因此程序内建一整套使用意图判断，正常操作完全不受影响：

| 规则 | 行为 |
|---|---|
| 其他修饰键按着时不启动 | 按住 Shift／Alt／Win 的情况下按 Ctrl，不会开始录音（输入法切换等组合键不会误触） |
| 按住不到 0.5 秒 | 自动取消，快速点一下 Ctrl 不会录音 |
| 录音中按任何其他键 | **立即取消**——例如按下 Ctrl 后临时改按 Ctrl+C，录音马上取消，复制照常进行 |
| 录音短于 0.8 秒 | 自动丢弃，不产出垃圾文字 |
| 识别结果为空 | 完全不送出贴上按键，键盘不会残留怪字符 |
| 自动贴上后 0.2 秒内 | 贴上用的模拟 Ctrl 不会被误判成新的录音指令 |

## 贴上与剪贴板

- 识别完成后，程序以模拟 `Ctrl+V` 贴上文字，并**自动还原您原本的剪贴板内容**（纯文字部分）
- 贴上目标在**按下热键那一刻**就锁定为当时的前台窗口；识别完成后程序会把焦点带回该窗口再贴上，避免贴错地方
- Voxinel 自己的窗口、任务栏、开始菜单等系统界面不会成为贴上目标

## 全局性规则

- PTT 在**倾听模式启用中**或 **AI 助手窗口开启时**会暂时停用，避免干扰
- 热键修改后立即生效，不需重启程序
