# 12 常见问题与疑难排解

## 语音输入

### 按住 Ctrl 说话，放开后没有文字出现？

依序检查：

1. **说话时间是否太短**——少于 0.8 秒的录音会自动丢弃（防误触设计）
2. **是否设置了识别来源**——设置页「语音辨识来源」至少要有一个；全部来源失败时也不会有文字
3. **模型是否下载完成**——重新打开设置窗口，缺模型时会自动跳出下载窗口
4. **是否在录音中按了其他键**——录音中按任何其他键都会立即取消

### 文字被贴到错误的窗口？

贴上目标在「按下热键那一刻」锁定，识别完成后程序会自动把焦点带回该窗口再贴上。少数特殊应用（全屏游戏、以系统管理员权限运行的窗口）可能不接受模拟贴上。

### Ctrl 跟输入法切换／其他快捷键打架？

录音中按任何其他键会立即取消录音，Ctrl 会完整让给原快捷键；按住 Shift／Alt 等修饰键时按 Ctrl 也不会触发录音。若仍有困扰，可在设置页把热键改为 `Ctrl + Win` 等组合键。

### 键盘偶尔残留怪字符？

v0.5.10 已修正（空识别结果不再送出模拟贴上按键）。请更新到最新版本。

## 各模式

### 倾听模式的文字贴到别的窗口？

倾听模式的贴上目标在**开启模式那一刻**锁定。换窗口：先连按两下右 Ctrl 关闭，到目标窗口再开启。

### 即时字幕／会议模式开启后没有字幕？（Windows）

1. 确认正在发声的设备是 Windows **默认**播放设备——采集的是默认设备的混音
2. 蓝牙耳机等非默认设备播放时收不到，先到声音设置切换默认设备
3. macOS / Linux 不支持系统音频采集

### 会议模式大家都显示 unknown？

- 少于 0.5 秒的片段一律标 unknown，请以正常速度说话
- 声纹需要累积，同一人说越多句越准
- 到「声纹辨识管理」把 `Speaker_N` 改名为真实姓名，之后的记录就会显示名字

### AI 助手叫不醒？

1. 确认设置页「AI 助手模式」已启用（默认开）
2. 其他模式（倾听／字幕／会议）进行中时不会背景监听
3. 唤醒词要完整说出并被正确识别；最可靠的是直接按 `Ctrl+Shift+L`
4. 助手窗口开启时 PTT 会停用，这是防误触设计

### 设置窗口不小心关掉了？

按 X 只是缩回托盘。点系统托盘图标 →「设置」即可再开启。

## AI 功能

### AI 校稿／摘要没有作用？

1. 确认设置页已勾选对应功能
2. 确认 LLM 端点可用（见[AI 功能与 LLM 设置](10-ai-features.md)）：本机 Ollama 是否运行、模型名称是否正确
3. 端点在程序启动时做健康检查——若启动当下 Ollama 还没开，开好后重启 Voxinel

### AI 助手一直停在「思考中」？

检查 Base URL、模型名称、API Key。使用 Ollama 时，用 `ollama list` 确认设置的模型存在。

## 引擎与模型

### 模型下载失败或太慢？

- 简体中文系统会自动使用镜像站加速；若您在中国大陆网络环境但系统不是简体中文，可暂时把设置页的界面语言设为「简体中文」再下载
- 确认磁盘剩余空间至少 600MB
- 下载中断的话，重新开启设置窗口即可再次触发下载

### 可以只用云端引擎吗？

可以。把云端来源排第一位即可，按住说话流程不变，只是没有边说边出字的即时显示（见[引擎说明](08-engines.md)）。

## 平台与其他

### macOS / Linux 支持度？

可安装、可使用基本语音输入、支持开机自启；但「即时字幕」「会议模式」（系统音频采集）与「自动贴上」目前仅在 Windows 实现。

### 如何诊断问题？

以 `--debug` 参数启动，会开启控制台窗口显示详细信息。Voxinel 平时不写日志文件。
