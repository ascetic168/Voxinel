# 05 即时字幕模式 🧪

把**电脑正在播放的声音**即时转成字幕：视频、线上课程、演讲、通话另一端的声音，都会在屏幕下方即时显示字幕；关闭时自动存成文字记录文件。

> ⚠️ 需采集系统音频回路（loopback），目前**仅支持 Windows**。🧪 表示实验性功能。

## 开启／关闭

1. 系统托盘菜单 →「即时字幕模式」
2. 屏幕下方出现**紫色外框**的字幕窗口，开始显示字幕
3. 再点一次菜单（此时显示「关闭即时字幕」）即结束并自动存档

## 字幕窗口

- 默认显示 **5 行**字幕（可在设置页调整 3–15 行），自动滚动到最新一句
- 同一行内：**蓝色**为已确定文字，**琥珀色**为即时预测
- 实验特性「中途修正」：句子还在进行时，SenseVoice 会提前对前段音频做离线识别，把已修正的内容提前以蓝色呈现，后面尚未修正的续接琥珀色，让长句不必等到整句说完才看到高品质文字

## 记录文件

关闭模式时自动保存到 `Documents\Voxinel\caption_YYYYMMDD_HHMMSS.txt`：

```
# 即时字幕记录 — 2026-10-31 14:05:00
# 时长: 123.4 秒
[14:05:02] 这里是第一句字幕
[14:05:09] 这里是第二句字幕
```

若启用「AI 辅助校稿」，存档前会先以 LLM 修正错别字与标点（见[AI 功能与 LLM 设置](10-ai-features.md)）。托盘菜单「打开记录档目录」可快速打开存放文件夹。

## 常见问题

- **字幕完全没动？** 本模式采集的是 Windows **默认播放设备**的混音。若声音从非默认设备（如蓝牙耳机）播出，请先到 Windows 声音设置把该设备设为默认
- 远程桌面等听不到系统声音的环境无法使用
- 开会请改用功能更完整的[会议模式](06-mode-conference.md)（含麦克风与说话人标识）
