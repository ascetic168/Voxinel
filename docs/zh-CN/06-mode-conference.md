# 06 会议模式与声纹识别 🧪

同时采集**麦克风（近端：您说的话）**与**系统音频（远端：对方或会议播放的声音）**，双字幕即时显示；关闭时自动合并成带时间戳与说话人标识的逐字稿，并可自动产生 AI 会议摘要。

> ⚠️ 远端音频采集（loopback）目前**仅支持 Windows**。🧪 表示实验性功能。

## 开启／关闭

1. 系统托盘菜单 →「会议模式」（需已下载流式模型）
2. 屏幕**上方**出现紫色「🔊 远端」字幕窗口、**下方**出现绿色「🎤 近端」字幕窗口
3. 结束时点托盘菜单（显示「关闭会议模式」），自动存档

## 回音抑制

远端的声音从扬声器播出来时也会进到您的麦克风，造成「同一句话被录两次」。会议模式内建回音抑制：检测到远端说话时暂时忽略麦克风音频，远端停止说话约 0.5 秒后恢复收音。**搭配耳机使用效果最佳**。

## 说话人声纹标识

- 内建声纹识别：每位首次出现的说话人会自动注册为 `Speaker_1`、`Speaker_2`……不需手动建档
- 之后听到同一人，字幕与逐字稿会标识 `[Speaker_1]`；累积发言越多，识别越稳定
- 少于 0.5 秒的短片段一律标为 unknown（不明说话人）

### 声纹辨识管理

系统托盘菜单 →「声纹辨识管理」开启管理窗口：

| 操作 | 作用 |
|---|---|
| 重新命名 | 把 `Speaker_1` 改成真实姓名，之后的记录文件与字幕就会显示该名字 |
| 删除 | 移除某位说话人的声纹数据 |
| 合并 | 重新命名成既有名字时，会询问是否把两笔声纹合并为同一人 |

声纹数据存放于模型目录下的 `speaker\speakers.db`（SQLite），**只存在本机**。

## 逐字稿与 AI 摘要

关闭模式时依序执行：

1. 近端与远端文字依时间排序合并，存为 `Documents\Voxinel\conference_YYYYMMDD_HHMMSS.txt`。同一发言人连续发言合并为一个区块，只在区块首行标时间与发言人：

```
# 会议记录 — 2026-10-31 14:00:00
# 时长: 1830.0 秒 | 远端: 42 段 | 近端: 18 段

[14:00:12] 远端 [Speaker_1]：
大家早安，我们开始今天的会议
今天主要讨论三件事

[14:00:25] 近端：
好的，我先报告上周进度
```

2. 若启用「AI 辅助校稿」→ 先以 LLM 修正错别字与标点再存档
3. 若启用「AI 会议摘要」→ 额外产生 `conference_summary_YYYYMMDD_HHMMSS.md`，内容包括摘要、与会者、讨论主题、重要决议、行动项目等段落（见[AI 功能与 LLM 设置](09-ai-features.md)）

## 仅记录、不显示字幕

设置页 →「系统设置」→ 勾选「会议模式：隐藏即时字幕窗口（仅记录）」：会议中不会出现任何 Overlay 窗口，只在背景识别与存档，适合不想让画面出现字幕的正式场合。

## 使用建议

- 会议中戴耳机，回音抑制效果最佳
- Google Meet、Teams 等会议软件的声音会经系统音频采集，不需另外设置
- 远端听不到时，检查会议播放设备是否为 Windows 默认播放设备
