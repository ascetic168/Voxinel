# 07 语音识别来源（ASR 引擎）

Voxinel 支持三种语音识别来源，可同时设置多个并排定**优先顺序**：识别时从第一位开始尝试，失败自动换下一个（Fallback）。

## 本地双引擎（默认，免密钥）

| 引擎 | 角色 | 说明 |
|---|---|---|
| 流式 Zipformer | 即时识别 | 中英双语流式模型，边说边出字；用于按住说话的即时显示，以及倾听／字幕／会议模式 |
| SenseVoice-Small（INT8） | 离线修正 | 高精度离线识别，支持中、英、日、韩、粤，自动加标点 |

- 全程在本机 CPU 运算，音频不出电脑
- 模型首次启动自动下载（合计约 600MB）；简体中文系统自动改用镜像站加速
- 模型位置见[文件与数据位置](10-data-and-files.md)

## 腾讯云 ASR

- 服务：SentenceRecognition（单句同步识别）
- 需在腾讯云控制台取得 **Secret ID** 与 **Secret Key**
- 可选引擎模型：

| 模型 | 语言 |
|---|---|
| `16k_zh` | 普通话 |
| `16k_zh_video` | 普通话（视频场景） |
| `16k_en` | 英文 |
| `16k_yue` | 粤语 |
| `16k_ca` | 川渝方言 |

## Google Gemini

- 云端 AI 语音识别，需 **API Key**（自 Google AI Studio 取得）
- 可选模型：`gemini-3.5-transcribe`（默认）、`gemini-3.5-flash`、`gemini-3.5-flash-lite`、`gemini-3.8-flash`
- 自动加标点、自动移除语气词；输出语言跟随界面语言设置（繁中／简中／日／韩／英，其他情况依音频实际语言）
- 注意：Gemini 的结果**不做繁简转换**——它会直接照设置的输出语言给文字

## 优先顺序与自动 Fallback

设置页「语音辨识来源」区块：

- **新增来源**：填入任一来源的凭证即自动启用并加入清单
- **▲／▼**：调整优先顺序（数字小的先识别）
- **✕**：移除来源
- **测试连线**：检查目前选定来源的设置

识别流程：从第一位开始尝试 → 该来源失败（未填密钥、网络错误、额度问题）→ 自动换下一个 → 全部失败则这次不出文字。

> **即时显示只跟第一位有关**：流式边说边出字只在「本地引擎排第一」时启用。排第一的是云端引擎时，流程变成放开热键后整段送往云端、完成后贴上，画面没有即时预览。

## 环境变量（高级）

凭证也可以用环境变量提供（设置页未填时的后备）：

| 变量 | 用途 |
|---|---|
| `TENCENTCLOUD_SECRET_ID` / `TENCENTCLOUD_SECRET_KEY` | 腾讯云凭证 |
| `GEMINI_API_KEY` | Gemini 密钥 |
