# 07 AI 助手模式

背景常驻的语音问答助手：平常静静听着麦克风，听到唤醒词就进入对话。您用说的提问，AI 以丰富格式文字回答，并同步用语音念出重点。

## 启用方式

| 方式 | 说明 |
|---|---|
| 唤醒词 | 默认「小花同学」，可在设置页自定义。听到后助手会回「我在。」并开始聆听您的问题 |
| `Ctrl+Shift+L` | 跳过唤醒词，直接弹出对话窗口进入对话——最可靠的方式 |

- 此模式**默认启用**：只要流式模型已下载，程序启动后就会自动在背景待命
- 背景监听只在其余模式都闲置时进行（模式互斥）

## 对话窗口

- 窗口约占屏幕 80%，置顶显示；**点窗口其他地方即关闭**（结束对话并停止语音），底部输入列的点击不会关闭
- 状态徽章会显示：**聆听中**（等您说话）→ **思考中**（AI 生成中）→ 回复内容
- 使用者发言为蓝色、AI 回复为紫色；画面保留最近 15 行对话
- **文字输入列**：不方便开口时，直接在底部输入框打字送出（Enter 送出）
- 回复支持 **Markdown**、表格、程序代码、**KaTeX 数学式**（`$...$` 行内、`$$...$$` 独立）、**Mermaid 图表**与 SVG 图形
- 对话具多轮上下文，可以直接追问

## 语音回复（TTS）

- **默认开启**：回复同时以语音念出口语精简版（2–4 句），屏幕上仍显示完整内容
- 设置页可选 **103 种音色**（中文男声／中文女声／英文女声）、调整语速 0.5x–2.0x、按「🔊 试听」预听
- 语音播放期间会暂时忽略麦克风，避免助手听到自己的声音又触发识别

## 什么情况会叫不动

- 唤醒词要**完整说出**并被正确识别；太短或含糊的音节会被当成杂音忽略
- 其他模式（倾听／字幕／会议）进行中时，背景监听暂停
- AI 助手窗口开启时，PTT 暂时停用——这是 v0.5.9 起的防误触设计，避免说话内容被误贴到别的窗口

## 助手的大脑：LLM 设置

AI 助手使用 OpenAI 兼容的 LLM 端点，默认指向本机 Ollama（`http://localhost:11434`，模型 `gemma4:latest`）。可改用 OpenAI、OpenRouter 等云端服务，设置方式见[AI 功能与 LLM 设置](10-ai-features.md)。另外可在设置页填写「附加提示词」，自定义助手的角色与回答风格。
