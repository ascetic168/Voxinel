# 08 设置页完整参考

开启方式：系统托盘菜单 →「设置」。修改后按「**保存设置**」才会生效；「取消」还原未保存的变更。设置窗口按 X 只是缩回托盘。


## 语音辨识来源

| 栏位 | 说明 | 默认 |
|---|---|---|
| 来源清单 | 已启用的识别来源，编号即优先顺序；点项目展开详细设置 | 本地 Offline (SenseVoice) |
| ▲ / ▼ / ✕ | 调整顺序／移除来源 | — |
| Provider / 模型 | 选择来源与模型（各来源可选模型见[引擎说明](07-engines.md)） | — |
| 凭证栏位 | 依来源不同：Secret ID／Secret Key（腾讯云）、API Key（Gemini）、模型目录（本地，一般不需修改） | 空 |
| 测试连线 | 检查目前选定来源的设置 | — |

> 未设置任何来源时，页面会显示警示「请至少设置一个语音辨识来源」。

## 识别设置

| 栏位 | 说明 | 默认 |
|---|---|---|
| 快捷键 | 按住说话的热键组合（五选一，见[快捷键](02-hotkeys.md)） | `Ctrl`（单键） |
| 简繁转换 | 自动（依系统地区）／正体中文／不转换；流式与最终结果皆适用 | 自动 |

## 语言

| 栏位 | 说明 | 默认 |
|---|---|---|
| 界面语言 | 自动（检测系统语言）／繁体中文／简体中文／English | 自动 |

## 语音活动检测（VAD）

| 栏位 | 说明 | 默认 |
|---|---|---|
| 过滤静音片段 | 自动略过静音与停顿，避免背景噪音被识别成怪字 | ✅ 开 |
| 敏感度 | 0.1–0.9。**数值越低越敏感**（越多声音通过），越高过滤越严格 | 0.50 |

## 系统设置

| 栏位 | 说明 | 默认 |
|---|---|---|
| 系统开机时加载执行 | 开机自动启动 Voxinel | ❌ 关 |
| 会议模式：隐藏即时字幕窗口（仅记录） | 会议模式不显示 Overlay，仅背景识别与存档 | ✅ 开 |

## AI 辅助校稿

| 栏位 | 说明 | 默认 |
|---|---|---|
| 启用 AI 校稿 | 关闭字幕／会议模式时，先以 LLM 修正文稿（错别字、标点、合并断句）再存档 | ❌ 关 |
| Base URL | OpenAI 兼容 API 地址；Ollama 或 OpenAI 填根目录即可，其他服务需含完整路径 | `http://localhost:11434` |
| 模型名称 | LLM 模型 id | `gemma4:latest` |
| API Key | 留空表示不需认证（如本机 Ollama） | 空 |

## AI 会议摘要

| 栏位 | 说明 | 默认 |
|---|---|---|
| 启用 AI 会议摘要 | 会议结束存档时自动产生结构化摘要；使用与 AI 校稿**相同的 LLM 设置** | ❌ 关 |## 关于
