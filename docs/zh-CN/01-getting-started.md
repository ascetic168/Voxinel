# 01 开始使用

## 系统需求

| 项目 | 需求 |
|---|---|
| 操作系统 | Windows 10 / 11（完整功能）；macOS、Linux 可安装但有限制（见下方注意） |
| 麦克风 | 使用语音输入、倾听、会议模式时需要 |
| 磁盘空间 | 首次下载模型约需 **600MB** |
| 网络 | 仅首次下载模型需要，之后**完全离线** |
| GPU | **不需要**。纯 CPU 即可流畅运行 |

> **macOS / Linux 注意**：设置、语音输入基本功能、开机自启皆可用；但「即时字幕」与「会议模式」依赖的系统音频采集（loopback），以及识别结果的自动贴上，目前仅在 Windows 上实现。详见[常见问题](11-faq.md)。

## 安装

1. 前往 [GitHub Releases](https://github.com/ascetic168/Voxinel/releases) 页面下载最新版安装包
2. 运行安装程序，完成后 Voxinel 会常驻在系统托盘（任务栏右下角的 🎤 图标）
3. Voxinel 是单实例程序：重复启动不会开出第二份，只会聚焦到原有进程

## 首次启动与模型下载

1. 第一次启动时，设置窗口会自动开启，并跳出「正在下载语音辨识模型...」窗口，自动开始下载
2. 下载顺序：离线识别模型（SenseVoice）→ 流式识别模型（Zipformer）→ VAD → 声纹识别
3. 进度条会显示目前项目与「已下载 / 总大小」；全部完成后显示「模型下载完成」并自动关闭
4. 下载完成即可使用，**无需申请任何 API 密钥**

模型合计约 600MB，存放于系统模型目录（位置见[文件与数据位置](10-data-and-files.md)）。若下载失败，重新打开设置窗口即可再次触发下载。

> **中国大陆网络加速**：系统语言为简体中文时，模型下载会自动改用镜像站（hf-mirror.com），不需手动设置。

## 系统托盘

Voxinel 平时常驻系统托盘，**左键点击一下图标**即可开启菜单：

| 菜单项目 | 作用 |
|---|---|
| 倾听模式 | 开启／关闭[倾听模式](04-mode-listening.md)（启用时显示「关闭倾听模式」） |
| 即时字幕模式 | 开启／关闭[即时字幕模式](05-mode-caption.md) |
| 会议模式 | 开启／关闭[会议模式](06-mode-conference.md) |
| 声纹辨识管理 | 开启[说话人声纹管理窗口](06-mode-conference.md#声纹辨识管理) |
| 设置 | 开启[设置窗口](08-settings.md) |
| 打开记录档目录 | 用资源管理器打开记录文件夹（`Documents\Voxinel`） |
| 結束 | 完全退出 Voxinel |

设置窗口按 X 关闭只是缩回托盘，程序仍继续运行；要完全退出请用托盘菜单的「結束」。

## 开机自动启动

设置窗口 →「系统设置」→ 勾选「系统开机时加载执行」，三个平台（Windows / macOS / Linux）皆支持。

## 更新程序

Voxinel **不会自动更新**。新版发布时，到 [Releases](https://github.com/ascetic168/Voxinel/releases) 下载新安装包直接安装即可，原有的设置与模型都会保留。
