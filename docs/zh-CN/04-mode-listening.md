# 04 倾听模式

连续听写：开启后 Voxinel 持续聆听麦克风，**每说完一句就自动识别并贴上一句**，直到您关闭为止。适合长段落口述、边想边说的场景。

## 开启／关闭

- **连按两下右 `Ctrl` 键**（1 秒内按两下）— 再操作一次即关闭
- 或从系统托盘菜单点「倾听模式」切换

## 使用要点

- **贴上目标在开启模式那一刻锁定**为当时的前台窗口，之后每一句都贴到那里。想换窗口：先关闭模式，到目标窗口再开启
- 每一句都经过 SenseVoice 离线修正并自动加标点
- Overlay 显示「🎙️ Mic 傾聽」标签（此标签固定为繁体显示）并有**绿色呼吸灯外框**，方便确认目前状态
- 关闭时，已录到但尚未识别完的句子会先贴完才结束（排空行为），不会漏字
- **此模式不产生记录文件**——输出只有贴上的文字；需要留档请改用[即时字幕](05-mode-caption.md)或[会议模式](06-mode-conference.md)

## 典型使用流程

1. 把光标放到要输入文字的地方（例如编辑器）
2. 连按两下右 Ctrl 开启倾听模式
3. 开口说话——每说完一句，该句自动出现在光标位置
4. 讲完后再连按两下右 Ctrl 关闭

## 与其他模式的关系

- 开启倾听模式时，其他模式（字幕／会议）会自动停止（模式互斥）
- 倾听模式启用中，按住说话（PTT）暂时停用，避免同时录音
