# 03 按住说话（PTT）

默认的语音输入方式：按住热键说话，放开后识别完成自动贴上。这是最接近「用说的打字」的模式。

## 基本流程

1. 按住 `Ctrl`（或您设置的组合键）开始说话
2. 说话同时，屏幕下方的 Overlay 浮动窗口**边说边出字**（流式识别）
3. 放开热键，离线引擎（SenseVoice）对整段音频做高精度识别与标点修正
4. 修正后的文字自动**贴上**到您按热键时的目标窗口
5. 原本剪贴板的内容自动还原

## Overlay 显示说明

Overlay 浮动窗口出现在主屏幕下方中间，不会抢走焦点（点击与输入仍作用在您的工作窗口）：

| 颜色 | 意义 |
|---|---|
| 浅蓝色文字 | 已确定的识别结果 |
| 琥珀色（淡黄）文字 | 流式即时预测，尚待修正 |

放开热键后，琥珀色的部分会被 SenseVoice 的高精度结果（含标点）替换，然后贴上并关闭 Overlay。

## 双引擎如何协作

- **流式引擎（Zipformer）**：按下热键的瞬间就开始识别，负责即时反馈，让您边说边确认
- **离线引擎（SenseVoice）**：放开后对完整音频重新识别，负责最终品质，支持中、英、日、韩、粤，自动加标点

## 什么情况会取消或不出文字

- 按住不到 0.5 秒、或录音短于 0.8 秒 → 自动取消／丢弃
- 录音中按了任何其他键 → 立即取消（放开前想喊停，按任意键即可）
- 识别结果为空 → 不贴上
- 全部细节见[快捷键与防误触](02-hotkeys.md)

## 使用云端引擎时的差异

把[腾讯云或 Gemini 排在第一位](07-engines.md)时，一样按住说话、放开贴上，但**没有边说边出字**：放开后整段音频（先经 VAD 去除静音）送往云端识别，完成后贴上。想保留即时显示，请把本地引擎排在第一位。

## 小技巧

- 说太短（<0.8 秒）没有结果是正常的防误触行为，不是坏了
- 若放开后离线修正迟迟未回来（超过 5 秒），程序会直接贴上流式结果，不会让您卡住
- 识别期间切换窗口也不用担心——贴上目标在按热键当下已锁定，程序会自动带回焦点
